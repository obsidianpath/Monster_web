⚙ Настройки монстрика

Если монстр не слышит класс — поднимайте. Для тихого микрофона ставьте 20–30x.
Меньше — чувствительнее. Калибровка —
0 — мгновенно на резкий звук. 2–3 сек — ловит продолжительный бубнёж.
Сколько должно быть тихо, чтобы монстр сам заснул.
Громкость рыка при пробуждении.
